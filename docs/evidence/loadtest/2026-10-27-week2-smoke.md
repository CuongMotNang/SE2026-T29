## Kiểm tra ngưỡng thất bại

API thử cổng `18001` bật `BOOKING_FAULT_MODE=error`, `BOOKING_FAULT_RATE=1`,
`BOOKING_FAULT_UNTIL` sau lúc bắt đầu 5 phút. Chạy k6 với `DURATION=5s`.

- 43 request, trong đó 11 request tạo booking trả 500; tỷ lệ 5xx 25,58%.
- Không có booking tạo thành công; không gửi DELETE cho ID chưa tạo.
- `http_server_errors`, `http_req_failed`, `checks`, `bookings_completed` vượt ngưỡng.
- k6 trả **exit code 99**, vẫn xuất summary JSON với các threshold `ok: false`.

Kết quả gốc: [summary khi có fault](2026-10-27-week2-fault-smoke.json).
